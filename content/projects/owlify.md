## Owlify

Command-line tool that simplifies fetching and formatting of JIRA issue data for reporting and visualization.

![Owlify Screenshot](/images/owlify.png)

### Features
- Fetch JIRA issues via command line
- Format data for reports
- Export to various formats (table, JSON, CSV)
- Customizable queries using JQL
- Easy integration with other tools
- Sprint and board data retrieval

### Technology
- Command-line interface
- Python
- JIRA API integration
